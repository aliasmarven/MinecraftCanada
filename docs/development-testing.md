# Development and Testing Environment

## Project

Unofficial Canadian Content (UCC), a community-maintained port
of Canadian Content 1.1.0 by xen-42 to Minecraft Java Edition 26.3.

Original project:
https://github.com/xen-42/MinecraftCanada

Unofficial port:
https://github.com/aliasmarven/Unofficial-Canadian-Content

## Primary Development Environment

The unofficial port has been developed and tested primarily
using the following desktop system:

- Operating system: Linux Mint Cinnamon
- Computer: HP Pavilion Gaming Desktop TG01 series
- Processor: Intel Core i5-10400F
- Graphics: NVIDIA GeForce GTX 1650, 4 GB VRAM
- Installed system memory: 8 GB RAM
- Minecraft development target: Java Edition 26.3
- Java development version: 25
- Fabric Loader: 0.19.5
- Fabric API: 0.162.0+26.3
- TerraBlender: 26.3.0.0.9

Development builds and test clients have been run with
a constrained Gradle configuration, including a 2 GiB
maximum Gradle JVM heap and one Gradle worker.

## Important Limitations

This describes the primary development and testing
environment. It is not a statement of minimum Minecraft
system requirements.

Successful testing on Linux Mint does not establish
compatibility with every operating system or hardware
configuration.

Dedicated-server compatibility and broader multiplayer
testing require separate verification.
